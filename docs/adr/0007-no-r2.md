# 0007 — Do not provision R2

**Status:** Accepted

## Context
The master prompt lists R2 among available services, and there is a temptation to provision
everything "in case". There is no requirement for binary object storage: answers and prayers
are text, avatars/images are not part of the product, and static assets live with the frontend.

## Decision
Do not add an R2 bucket.

## Consequences
- One fewer binding to secure and pay for.
- If a future need for object storage appears, it should be introduced with its own ADR.
